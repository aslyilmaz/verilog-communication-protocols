# verilog-communication-protocols
Verilog implementations of UART and I2S controllers with self-checking testbenches.

**Author:** Aslı Yılmaz  
**Institution:** Middle East Technical University - Electrical and Electronics Engineering  
**Date:** October 2026

This repository contains the complete RTL implementation and verification suite for custom I2S (Inter-IC Sound) and UART (Universal Asynchronous Receiver-Transmitter) controllers.

**Tools Used:** Verilog HDL, Xilinx Vivado
